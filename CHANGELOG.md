## [v0.1.0] - 2026-10-02

### Added

- **25 PATH checks**, worst first, each with what, why and fix.
- **Health ratings by worst problem**, not a score
  (ten tidy-ups can't hide one open door).
- **Dashboard** — the ratings, what's holding them up, every problem.
- **System and User pages** — stored text, expansions, who can write.
- **Fixes on the entry they're about**, staged until you say.
- **Review** — before-and-after ratings and every change, then one Apply.
- **Folder lock-downs**, with the icacls equivalent to copy.
- **Move a system entry to your user PATH**, never lost half-way.
- **One UAC prompt per apply**; none for user-only changes.
- **History and Undo** (the undo is undoable too, for the indecisive).
- **No applying over changes made since the scan.**
- **Shadowing** — which file a command runs, and what it hides.
- **Sandbox-escape check** for PATH folders Low-integrity code can write.
- **Your own writable folders are a note, not a problem**
  (malware running as you can edit your PATH anyway).
- **System32-missing check**, after a PC with no PATH rated spotless.
  Technically there was nothing wrong with it.
- **Learn** — seven optional articles, linked from the problems.
- **Redacted snapshot export**, so bug reports don't list your projects.
- **`pathology scan` and `pathology snapshot`** on the command line.
- **Network paths left alone** unless you opt in.
- **In-app updates**, with an optional "What's new".
- **An app icon**, crisp at every size, which is more than most PATHs can say.
